# DHES — Descargas

Aplicación de **Dulce Hogar del Espíritu Santo** (Biblia, planes de lectura, comunidad y grupos).

**Android** (última versión):
https://github.com/javiergarcia26/dhes-app-descargas/releases/latest/download/dhes-app.apk
Abre el archivo descargado y, si el teléfono lo pide, permite instalar apps de esta fuente (origen desconocido).

**Windows** (última versión):
https://github.com/javiergarcia26/dhes-app-descargas/releases/latest/download/dhes-app-windows-setup.exe
Si aparece "Windows protegió su PC" (SmartScreen): "Más información" → "Ejecutar de todas formas". En Windows se inicia sesión con correo y contraseña.

También puedes usarla en la web: https://dhes-app.web.app

Este repositorio solo contiene los instaladores publicados; no contiene código.
