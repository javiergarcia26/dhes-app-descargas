# DHES — Descargas

Aplicación para Android de **Dulce Hogar del Espíritu Santo** (Biblia, planes de lectura, comunidad y grupos).

**Descargar la última versión:**
https://github.com/javiergarcia26/dhes-app-descargas/releases/latest/download/dhes-app.apk

Para instalar: abre el archivo descargado y, si el teléfono lo pide, permite instalar apps de esta fuente (origen desconocido).

También puedes usarla en la web: https://dhes-app.web.app

Este repositorio solo contiene los instaladores publicados; no contiene código.
